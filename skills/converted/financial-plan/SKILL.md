# 财务规划（Financial Plan）

构建或更新全面的财务规划，涵盖退休规划、教育金规划、遗产规划和现金流分析。

## 描述

用于新客户入职、年度计划审阅或情景模拟，帮助个人或家庭评估财务目标和退休准备度。

## 触发条件

当用户需要：
- "帮我做财务规划"
- "退休计划"
- "我什么时候能退休？"
- "教育金规划"
- "遗产规划"
- "现金流分析"
- "财务计划审阅更新"

## 执行步骤

### Step 1: 客户画像

收集或确认以下信息：

**基本信息：**
- 年龄、配偶年龄、子女/被抚养人情况
- 预期寿命假设

**收入与就业：**
- 当前收入、预期涨幅、目标退休年龄
- 配偶收入情况

**账户与资产：**
- 所有投资账户及余额（401k、IRA、 taxable）
- 资产配置

**收入来源：**
- 工资、奖金、租金收入
- 社保金估算、养老金

**支出：**
- 当前年度支出
- 预期变化（还清房贷、子女独立等）

**负债：**
- 房贷、学贷、其他债务

**保险：**
- 寿险、残疾险、长期护理险、健康险

**遗产：**
- 遗嘱、信托、受益人指定、赠与策略

### Step 2: 现金流分析

构建年度现金流预测：

| 年份 | 年龄 | 总收入 | 税费 | 生活支出 | 储蓄 | 净现金流 |
|------|------|--------|------|---------|------|---------|
| | | | | | | | |

**关键假设：**
- 通胀率（通常 2.5-3%）
- 税率（边际和实际）
- 储蓄率及储蓄方向（税前、Roth、应税）

### Step 3: 退休模型

**积累阶段：**
- 当前组合价值
- 年缴金额（401k、IRA、应税）
- 各资产类别预期回报
- 蒙特卡洛模拟：不同支出水平下的成功概率

**分配阶段：**
- 退休后年支出（现值 → 通胀调整）
- 社保开始年龄和金额
- 养老金收入（如有）
- 组合提款率和提取顺序
- 最低强制分配（RMD）

**关键输出：**
- 退休时预期组合价值
- 可持续提款率
- 资金耗尽概率（目标 > 85%）

### Step 4: 教育金规划

- 目标院校类型（公立/私立）和当前费用
- 学费通胀率（通常 5%）
- 已有教育金储蓄
- 529 计划供款策略
- 奖学金和助学金预期

### Step 5: 遗产规划

- 当前净资产
- 遗产税免税额
- 赠与策略和年度免税额
- 信托结构建议
- 受益人更新需求

### Step 6: 情景分析

| 情景 | 假设变化 | 对退休影响 |
|------|---------|-----------|
| 基准情景 | 当前假设不变 | 目标成功概率 |
| 乐观情景 | 高回报 + 低通胀 | 提前退休或更高支出 |
| 悲观情景 | 低回报 + 提前退休 | 需调整支出或延后退休 |
| 紧急情景 | 重大医疗/长期护理 | 资产保护策略 |

## 输出规范

**报告结构：**
1. **执行摘要** — 当前状况、目标、关键发现
2. **客户画像** — 基本信息汇总
3. **现金流分析** — 年度现金流表
4. **退休分析** — 积累/分配模型 + 蒙特卡洛结果
5. **教育金分析** — 目标 vs 进度
6. **遗产规划** — 当前计划和建议
7. **情景对比** — 各情景下的成功概率和建议调整

**关键指标：**
- 退休准备度指数（目标资产 / 所需资产）
- 可持续提款率
- 资金耗尽概率
- 教育金完成率
