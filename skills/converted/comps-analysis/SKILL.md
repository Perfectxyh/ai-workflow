# 可比公司分析（Comps Analysis）

建立机构级的可比公司分析，包含运营指标、估值倍数和统计基准。

## 描述

构建专业的可比公司分析 Excel 模型，通过同行对比支持投资决策、估值定价和行业研究。

**适用场景：**
- 上市公司估值（并购、投资分析）
- 业绩对标 vs 行业同行
- IPO 或融资轮次定价
- 识别估值异常（高估/低估）
- 投资委员会演示材料

**不适用场景：**
- 无可比上市公司的私企
- 高度多元化的综合集团
- 困境/破产公司
- 尚未盈利的初创公司
- 独特商业模式的稀有公司

## 触发条件

当用户需要：
- "为[公司]做可比公司分析"
- "找一批可比公司和估值倍数"
- "行业估值基准研究"
- "估值区间定价参考"

## 执行步骤

### Step 1: 确定可比公司

选择 6-10 家可比上市公司：
- **行业/业务**：主营业务和收入结构相似
- **规模**：相近的营收规模和市值
- **增长阶段**：相近的增长率和成熟度
- **地域**：相似的市场环境和监管框架

**排除标准：**
- 最近发生重大并购重组的公司
- 财务数据失真的公司（如一次性大额损益）
- 业务模式正在剧烈转型的公司

### Step 2: 拉取关键财务数据

**运营指标：**
| 指标 | 用途 |
|------|------|
| 营收 | 规模基准 |
| 营收增长率 | 增长动力 |
| EBITDA | 盈利核心指标 |
| EBITDA 利润率 | 运营效率 |
| 净收入 | 归母利润 |
| 自由现金流 | 现金流质量 |

**市场数据：**
- 当前股价
- 总市值
- 企业价值（EV）
- 净债务 / 净现金

### Step 3: 计算估值倍数

| 倍数 | 计算方式 | 含义 |
|------|---------|------|
| EV/Revenue | 企业价值 / 营收 | 营收倍数 |
| EV/EBITDA | 企业价值 / EBITDA | 核心盈利倍数 |
| P/E | 股价 / EPS | 净利倍数 |
| P/B | 股价 / 每股净资产 | 账面价值倍数 |
| EV/FCF | 企业价值 / 自由现金流 | 现金流倍数 |

### Step 4: 统计分析

计算基准统计量：
- **平均值**和**中位数**（主要参考）
- **最大值**和**最小值**（异常值识别）
- **25%/75% 分位数**（估值区间）
- **标准差**（离散程度）

### Step 5: 可视化呈现

- 估值倍数柱状图（各公司 vs 中位数）
- 利润率 vs 增长率散点图
- 市场规模气泡图（按市值排序）

### Step 6: 结论提炼

1. **目标公司定位**：在同行中的估值分位
2. **估值区间**：基于 25%-75% 分位数
3. **异常值识别**：被高估/低估的公司及原因
4. **关键发现**：行业趋势和主要结论

## 输出规范

```
可比公司分析：[公司]（[股票代码]）
分析日期：[日期]

可比公司列表（6-10家）：
公司         市值(亿) 营收(亿) 增速%  EBITDA%  EV/EBITDA  P/E
──────────  ───────  ──────  ────  ──────  ────────  ────
[公司1]       XXX      XXX    X.X    X.X     X.Xx      X.X
[公司2]       XXX      XXX    X.X    X.X     X.Xx      X.X
...

统计摘要：
             EV/EBITDA  P/E  EV/Revenue  增速%
平均值         X.Xx     X.X    X.Xx      X.X
中位数         X.Xx     X.X    X.Xx      X.X
25%分位数      X.Xx     X.X    X.Xx      X.X
75%分位数      X.Xx     X.X    X.Xx      X.X

目标公司定位：
[公司]的 EV/EBITDA 为 X.Xx，处于同行第 X/10 位
相较于同行中位数（X.Xx）：高估/低估 X%
建议估值区间：XX - XX 元/股
```

## 注意事项

- MCP 数据源 > SEC EDGAR > 网络搜索（按优先级）
- 所有倍数需标注计算日期和来源
- 对异常值需做具体说明
- 考虑行业周期对倍数的影响
- 不同行业有不同关键倍数（如 SaaS 看 EV/Revenue，银行看 P/B）
