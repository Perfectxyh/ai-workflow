# 尽职调查清单（Due Diligence Checklist）

生成和跟踪全面的尽职调查清单，按行业、交易类型和复杂度定制。

## 描述

覆盖所有主要工作流，包含资料请求清单、状态跟踪和风险标记。用于启动尽职调查、组织资料室审阅或跟踪待办事项。

## 触发条件

当用户需要：
- "创建 DD 清单"
- "尽职调查跟踪表"
- "尽调资料需求清单"
- "我们还需要什么材料？"
- "资料室审阅清单"

## 执行步骤

### Step 1: 确定尽调范围

确认以下信息：
- **目标公司**：名称、行业、业务模式
- **交易类型**：平台收购、补强收购、成长性投资、资本重组、分拆
- **交易规模/复杂度**：决定尽调深度
- **关键关注点**：已知需优先处理的问题（客户集中度、监管、环境等）
- **时间线**：LOI / 交割目标时间

### Step 2: 生成工作流清单

**财务尽职调查**
- [ ] 盈利质量分析（QoE）— 营收和 EBITDA 调整
- [ ] 营运资本分析 — 实际 vs 正常化水平
- [ ] 债务及类债务项目
- [ ] 资本支出（维护性 vs 扩张性）
- [ ] 税务结构和风险暴露
- [ ] 审计历史与会计政策
- [ ] 备考调整（运行率、协同效应）

**商业尽职调查**
- [ ] 市场规模和增长（TAM/SAM/SOM）
- [ ] 竞争定位和市场份额
- [ ] 客户分析 — 集中度、留存率、NPS
- [ ] 定价能力和合同结构
- [ ] 销售管道和 backlog
- [ ] GTM 市场策略有效性

**法务尽职调查**
- [ ] 公司架构和组织结构图
- [ ] 重大合同（客户、供应商、合作伙伴）
- [ ] 诉讼历史与未决索赔
- [ ] 知识产权组合和保护
- [ ] 监管合规
- [ ] 员工协议与竞业禁止

**运营尽职调查**
- [ ] 管理团队评估
- [ ] 组织结构和关键人风险
- [ ] IT 系统和基础设施
- [ ] 供应链和供应商依赖
- [ ] 设施和房地产
- [ ] 保险覆盖范围

**人力资源尽调**
- [ ] 组织架构图和人员变动趋势
- [ ] 薪酬对标分析
- [ ] 福利和养老金义务
- [ ] 关键员工留存风险
- [ ] 文化评估
- [ ] 工会/劳资协议

**ESG 尽职调查**
- [ ] 环境合规和风险
- [ ] 碳排放和能源效率
- [ ] 社会影响和社区关系
- [ ] 公司治理结构
- [ ] 董事会构成和独立性
- [ ] ESG 报告和披露

### Step 3: 状态跟踪

| 工作流 | 项目数 | 已完成 | 进行中 | 待启动 | 红灯 |
|--------|--------|--------|--------|--------|------|
| 财务 | | | | | |
| 商业 | | | | | |
| 法务 | | | | | |
| 运营 | | | | | |
| 人力资源 | | | | | |
| ESG | | | | | |

### Step 4: 风险标记

对每个红灯事项：
- **描述**：具体问题
- **严重程度**：高/中/低
- **对交易影响**：估值调整、条款修改、交易终止
- **下一步**：需要额外信息或决策

## 输出规范

**格式：** Excel 跟踪表
**推荐结构：**
```
工作表1: 摘要仪表板
  - 各工作流完成进度
  - 红灯事项汇总
  - 关键里程碑时间线

工作表2: 详细清单
  - 按工作流分 sheet
  - 每个事项含：编号、类别、问题描述、状态、负责人、截止日期、备注

工作表3: 资料室索引
  - 已收到文档清单
  - 文档位置（虚拟资料室链接）
  - 待补充文档清单
```
