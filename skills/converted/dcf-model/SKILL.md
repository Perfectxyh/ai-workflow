# DCF 估值模型

建立机构级的 DCF（贴现现金流）模型，用于股权估值。

## 描述

从 SEC  filings 和分析师报告中提取财务数据，构建完整的现金流预测模型，包含 WACC 计算、敏感性分析，输出专业的 Excel 模型及摘要报告。

## 触发条件

当用户需要：
- 使用 DCF 方法对公司进行估值
- 请求内在价值分析
- 需要包含增长预测和终值的详细财务建模

## 执行步骤

### Step 1: 收集公司信息

获取目标公司的基本信息、行业分类、最新财报数据。

### Step 2: 运行同业对比分析

加载 comps-analysis Skill 建立交易可比公司：
1. 确定 4-6 家可比上市公司
2. 拉取运营指标（营收、EBITDA、利润率、增长率）
3. 拉取估值倍数（EV/Revenue、EV/EBITDA、P/E）
4. 计算统计摘要（中位数、25%/75% 分位数）

**关键输出：**
- 中位数 EV/EBITDA 倍数 → 指导终值退出倍数
- 中位数 EV/Revenue 倍数 → DCF 输出合理性校验
- 同行增长率 → 营收预测基准
- 同行利润率 → 利润率假设基准

### Step 3: 建立 DCF 模型

**3.1 数据收集**
- 历史财务报表（最近 3-5 年）
- 市场数据（股价、流通股数、净债务）
- 行业增长率和风险溢价

**3.2 营收预测**
- 建立 Bear / Base / Bull 三种情景
- 营收增长率假设（基于历史趋势 + 行业分析）

**3.3 利润表预测**
- 营业成本、SG&A、折旧摊销
- 税率假设
- 运营利润率趋势

**3.4 自由现金流计算**
- 计算 UFCF（无杠杆自由现金流）
- 资本支出假设
- 营运资本变动

**3.5 WACC 计算（资本资产定价模型）**
- 无风险利率（Rf）
- 市场风险溢价（MRP）
- Beta 系数
- 股本成本（Ke）= Rf + Beta × MRP
- 债务成本（Kd）
- 资本结构（D/E 比率）
- WACC = E/V × Ke + D/V × Kd × (1 - T)

**3.6 终值计算**
- 永续增长法：TV = FCF_n × (1 + g) / (WACC - g)
- 退出倍数法：TV = EBITDA_n × Exit Multiple

**3.7 贴现计算**
- 将预测期 FCF 和终值贴现到现值
- 企业价值（EV）= Σ贴现FCF + 贴现终值
- 股权价值 = EV - 净债务 + 现金
- 每股内在价值 = 股权价值 / 流通股数

### Step 4: 敏感性分析

构建 WACC × 终端增长率 的敏感性矩阵：
- 标准 5×5 矩阵
- 中心单元格 = 基准假设
- 突出显示基准场景

### Step 5: 估值校验

| 校验项 | 参考标准 |
|--------|---------|
| 隐含 EV/EBITDA vs 同行中位数 | 偏差应在 ±20% 内 |
| 终值占 EV 比重 | 应在 50%-70% |
| 隐含增长率 vs 同行增长率 | 需合理解释差异 |

### Step 6: 输出交付

1. **DCF 模型文件**（.xlsx）含：
   - 三种情景（Bear/Base/Bull）
   - 敏感性分析表
   - 估值摘要
2. **分析报告**含：
   - 关键估值驱动因素
   - 风险与敏感度分析
   - 投资建议

## 注意事项

- 所有预测单元格必须使用 Excel 公式而非硬编码
- 每项输入假设需标注来源
- 步骤之间需用户确认再继续
- 发现错误立即修正，避免下游全盘重算
