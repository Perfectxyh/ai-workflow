# 投资委员会备忘录（IC Memo）

撰写结构化的投资委员会备忘录，用于 PE 项目审批。

## 描述

整合尽职调查发现、财务分析和交易条款，形成专业 IC 文档。用于准备投资委员会、撰写项目报告或制作正式推荐方案。

## 触发条件

当用户需要：
- "写一份 IC 备忘录"
- "投资委员会项目报告"
- "项目推介材料"
- "推荐备忘录"
- "deal write-up"

## 执行步骤

### Step 1: 收集输入信息

从用户或对话历史中收集：
- 公司概述和业务描述
- 行业/市场背景
- 历史财务数据（3-5年）
- 管理层评估
- 交易条款（价格、结构、融资）
- 尽职调查发现（商业、财务、法务、运营）
- 价值创造计划 / 100天计划
- 回报分析（基准、乐观、悲观）

### Step 2: 撰写备忘录

**I. 执行摘要（1页）**
- 公司描述、交易逻辑、关键条款
- 推荐意见和预期回报
- 前 3 大风险和缓释措施

**II. 公司概览（1-2页）**
- 业务描述、产品/服务
- 客户基础和上市策略
- 竞争定位
- 管理团队

**III. 行业与市场（1页）**
- 市场规模和增长
- 竞争格局
- 长期趋势/顺势因素
- 监管环境

**IV. 财务分析（2-3页）**
- 历史业绩（营收、EBITDA、利润率、现金流）
- 盈利质量调整
- 营运资本分析
- 资本支出需求

**V. 投资逻辑（1页）**
- 为什么这是一个有吸引力的投资（3-5个支柱）
- 价值创造杠杆（有机增长、利润扩张、并购、倍数扩张）
- 100天优先事项

**VI. 交易条款与结构（1页）**
- 企业价值和隐含倍数
- 资金来源与用途
- 资本结构/杠杆
- 关键法律条款

**VII. 回报分析（1页）**
- 三种情景：基准、乐观、悲观
- IRR 和 MOIC 各情景对比
- 敏感性分析（进入倍数 × 退出倍数）
- 退出策略和预期时间线

### Step 3: 风险分析

| 风险类别 | 具体风险 | 概率 | 影响 | 缓释措施 | 责任人 |
|----------|---------|------|------|---------|--------|
| 商业风险 | | H/M/L | H/M/L | | |
| 财务风险 | | H/M/L | H/M/L | | |
| 执行风险 | | H/M/L | H/M/L | | |
| 市场风险 | | H/M/L | H/M/L | | |

### Step 4: 最终审核清单

- [ ] 所有数字与来源一致
- [ ] 回报计算正确
- [ ] 风险充分披露
- [ ] 推荐意见明确
- [ ] 格式符合委员会标准
- [ ] 执行摘要可独立阅读

## 输出规范

**格式：** Word 文档或 PDF，8-12页
**标准 IC 模板结构（7个章节）：**
1. 执行摘要
2. 公司概览
3. 行业与市场
4. 财务分析
5. 投资逻辑
6. 交易条款
7. 回报分析

**附录：**
- 尽职调查状态跟踪表
- 详细财务模型
- 管理层简历
