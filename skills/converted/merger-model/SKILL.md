# 并购模型（Merger Model）

构建并购交易的增厚/稀释分析，含备考 EPS 影响、协同效应敏感性和购买价格分摊。

## 描述

用于评估潜在收购、准备并购后果分析或就交易条款提供建议。核心输出是判断交易对收购方股东是增厚（Accretive）还是稀释（Dilutive）。

## 触发条件

当用户需要：
- "做并购模型"
- "增厚/稀释分析"
- "M&A 模型"
- "备考 EPS 分析"
- "并购后果分析"
- "交易影响分析"
- "评估收购[目标公司]"

## 执行步骤

### Step 1: 收集输入

**收购方：**
- 公司名称、当前股价、流通股数
- LTM 和 NTM EPS（GAAP 和调整后）
- P/E 倍数
- 税前债务成本、税率
- 账面现金、现有债务

**目标公司：**
- 公司名称、当前股价（如上市）、流通股数
- LTM 和 NTM EPS 或净利润
- 企业价值或股权价值

**交易条款：**
- 每股收购价格（或相对当前溢价）
- 对价结构：现金% vs 股票%
- 现金部分的新增融资利率
- 预期协同效应（收入端和成本端）及落地时间表
- 交易费用和融资费用
- 预期交割日期

### Step 6: 交易合理性检查

- [ ] 收购 PE 倍数 vs 收购方 PE 倍数（短期增厚/稀释）
- [ ] 协同效应占目标营收比例是否合理（通常 2-8%）
- [ ] 杠杆倍数是否在行业合理范围内
- [ ] 交割后信用评级影响
- [ ] 反摊薄效应（EPS accretion triggers）

## 输出规范

**模型结构（Excel）：**
```
Sheet 1: 输入假设
Sheet 2: 购买价格分析
Sheet 3: 资金来源与用途
Sheet 4: 备考合并报表
    4a: 备考利润表
    4b: 备考资产负债表
Sheet 5: 增厚/稀释计算 (Year 1-3)
Sheet 6: 敏感性分析
Sheet 7: 协同效应明细
```

**核心输出指标：**
- Year 1/2/3 EPS accretion/dilution %
- 备考杠杆比率（Debt/EBITDA）
- 协同效应 NPV
- 盈亏平衡协同效应（breakeven synergies）
