# 盈利分析报告（Equity Research Earnings Update）

制作专业的季度盈利分析报告，对标摩根大通、高盛等机构标准。

## 描述

分析已覆盖公司的季度财报业绩，生成 8-12 页的盈利更新报告（3,000-5,000 字），包含超预期/低于预期分析、关键指标更新、估值调整和投资观点更新。

## 触发条件

当用户需要：
- "为[公司]制作Q3 2024盈利更新"
- "分析[公司]的季度业绩"
- "财报后分析报告"
- "Q1/Q2/Q3/Q4更新"

## 执行步骤

### Step 1: 收集财报数据

获取最新季度财报关键数据：
- 营收及同比增长
- EPS（GAAP vs 调整后）
- EBITDA 及利润率
- 分部业绩（如有）
- 管理层指引（本季 + 下季）

### Step 2: 超预期/低于预期分析

**核心问题：**
- 是否超出/低于市场预期？
- 量化差异（如"营收超出预期 1.2 亿元，增幅 3%"）
- 分析业绩偏差的原因（一次性因素 vs 趋势性变化）

**比较基准：**
| 指标 | 实际值 | 预期值 | 差异% | 同比% |
|------|--------|--------|-------|-------|
| 营收 | | | | |
| EPS | | | | |
| EBITDA | | | | |
| 毛利率 | | | | |

### Step 3: 关键指标分析

重点分析 3-5 个核心驱动指标的变化：
- **营收质量**：有机增长 vs 收购增长 vs 汇率影响
- **利润率趋势**：毛利率、运营利润率变化及驱动因素
- **现金流**：经营现金流、自由现金流 vs 利润质量
- **资产负债表**：杠杆率、流动性、资本配置
- **分部表现**：各业务板块的增速和利润贡献

### Step 4: 估值更新

- 根据最新数据调整模型假设
- 更新目标价
- 调整评级（如适用）

### Step 5: 报告撰写

**报告结构：**

```
1. 关键结论（1段）
   - 超预期/低于预期定性
   - 核心观点更新
   
2. 业绩分析（2-3段）
   - 营收分析
   - 利润率分析
   - 分部表现
   
3. 管理层分析（1段）
   - 电话会关键信息
   - 指引变化
   - 战略更新
   
4. 估值与观点（1段）
   - 目标价调整
   - 评级变化
   - 风险因素
   
5. 图表（8-12张）
   - 股价走势
   - 营收/利润趋势
   - 估值区间
   - 同行对比
```

### Step 6: 数据验证

- 所有数字与原始来源核对
- 计算逻辑校验
- 报告格式合规性检查

## 输出规范

**报告格式：**
- 长度：8-12 页
- 字数：3,000-5,000 字
- 表格：1-3 张摘要表
- 图表：8-12 张
- 字体：Times New Roman

**必需的数据来源标注：**
- ✅ 盈利发布（含日期和链接）
- ✅ 10-Q 文件（含 SEC EDGAR 链接）
- ✅ 电话会记录（含日期）
- ✅ 投资者演示材料（如有）
- ✅ 一致预期来源（Bloomberg/FactSet 及日期）
- ✅ 前期指引（来自上季材料）

## 注意事项

- 发布时效：财报后 24-48 小时内完成
- 聚焦新信息，不重复公司背景
- 所有数据必须标注可点击的源链接
- 假设读者已熟悉公司基本面和覆盖报告
