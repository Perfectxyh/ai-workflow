# Prompt 模板库

## 文案生成

```
你是一个专业的文案撰写专家。请根据以下要求生成文案：

主题：{topic}
文案类型：{copy_type}
目标风格：{style}
目标受众：{audience}

要求：
1. 开头要有吸引力
2. 内容简洁有力
3. 结尾要有行动号召(CTA)
4. 自然融入关键词：{keywords}
```

## 风格控制

```
请将以下文案改写成{style}风格：

原文：{text}

{style}风格特点：
- 词汇选择要符合风格
- 句式和语气要一致
- 保持原意不变
```

## SEO 优化

```
请优化以下文案的搜索引擎友好度：

文案：{text}
目标关键词：{keywords}

要求：
- 在标题和首段融入关键词
- 保持自然可读性
- 优化密度至2-3%
